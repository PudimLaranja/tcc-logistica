# tcc-logistica

This is a project written in TypeScript using React and a Vite template, this project was made as a final project for the logistics technical course i was partaking. The project was about organizing the logistic of a massive event a Pizzaria was hired to do, so this website serve as our presentation of our idea. If you click on Login you will be redirect to a fake dashboard and if you click on the ticket icon you will be redirected to a conversation between me and my teammates that helped me make this project. This Conversation explains the idea of the project showing pictures and graphs of how our planning is possible.

- - -

Esse é um project escrito em TypeScript usando React é um template do Vite, para criar um projeto que serviu de apresentação do meu TCC do curso técnico de logística que eu fiz. O projeto era sobre organizar uma pizzaria para realizar um evento gigante, e sobre como a logística desse evento funcionaria. Se você clicar no ícone de login do site você sera redirecionado para uma dashboard falsa, mas se você clicar no ícone de ticket você vai ser redirecionado para uma conversa fictícia entre os membros do grupo que eu estava, em que a gente explica a nossa ideia para resolver os problemas logísticos desse evento. Essa conversa além de mensagens apresenta imagens e tabelas que ajudam na explicação da nossa solução.
